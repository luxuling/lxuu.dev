# Kenapa pakai Linux mas?

aku: lha wong saya suka kok 🙂

simpel kan jawaban nya hehehe, cuma ya seneng/suka pasti ada back story nya, and this is how i love linux and still use it as my daily driver.

![](/images/posts/kenapa-pakai-linux-mas/5b8e426a9ee765dcd6f82274fffe6092-mwpx5chd.jpg 'small')

## Windows mikocok

Sebenernya Linux itu bukan OS pertama yg aku pakai untuk ngoding, dulu aku pakai windows dari pertama kali belajar pemrograman, dan aku inget banget saat itu aku belajar di channel nya WPU dan Programmer Zaman Now, shout out to beliau” ini, karena hanya HTML, CSS, dan JS vanilla, semua masi terasa ringan, btw disitu aku pakai `Thinkpad T470 i5 gen 6, ram 8, ssd di 250gb`, untuk buka vscode dan chrome disitu masi ringan” aja, tapi buat belajar framework dan database dan run aplikasi development yg lain udah terasa berat banget.

![](/images/posts/kenapa-pakai-linux-mas/6b04c7ecfcbe53036b547f8692302f1a-mwpx6cyi.jpg 'small')

## Keterpaksaan

Setelah itu aku kenal linux dan berani switch ke linux karena intern pertama ku sebagai software engineer mengharuskan aku pakai linux, ya mau gimana lagi ya kan, aku coba deh tu pakai salah satu linux distribution yg basis nya adalah Arch bernama `Archcraft` dari [https://archcraft.io/](https://archcraft.io/) , kalo kalian ngira nya aku udah jago sama perlinuxan dan install Arch karena tau poin plus dan minus nya, yup kalian salah, aku blum tau hal hal mendalam terkait Arch sebagai distro itu sendiri seperti apa, apa behaviour nya dan system nya seperti apa, yg aku tau `Archcraft` bagus tema nya dan ringan katanya, yaa aku install aja dong hehehe.

Awal nya si ga ada masalah, aku coba belajar-belajar di tengah jalan gimana cara menggunakan si Archcraft ini, dan emang ringan barang ini, gokil lah pokok nya, love it so much, Windows buang aja hihihihi (candaaaa), dan asli pakai linux itu install sesuatu itu relative gampang dan simpel (normal nya ya iniii)

![](/images/posts/kenapa-pakai-linux-mas/e0d171bb1c3d5dbb36f73eedf3df59fd-mwpxboqj.jpg 'small')

## Tragedi

And then terjadilah sebuah masalah, dimana disitu aku baru mau set up project baru karena di invite buat join ke sebuah project, seperti biasa aku set up environment buat develop project tersebut, tpi ada masalah di installasi beberapa dependency nya, mana di situ project nya lagi critical lagi, rusuh banget lah pokok nyaa, disitu aku makin deg deg, keringet dingin, alhasil seharian ga bisa resolve itu problem nya (pure skill issue ini bang hehehe :>), akhir nya aku pindah ke Ubuntu, dan akhir nya bisa deh tu walaupun harus install semaleman biar besok nya bisa langsung kerja.

![](/images/posts/kenapa-pakai-linux-mas/22274e0abcd12978a73934d3ae4ae876-mwpxatm4.jpg 'small')

Dan memang si Ubuntu ini tu lebih berat dan ga se lancar Archcraft dengan laptop ku yg kentang ini jujuurr aga menyiksa, and then di weekend aku coba switch lagi ke distro lain, yaitu Mint, and Linux Mint lah yg sampe akhir menemani sampai intern tersebut selesai yeeeyyyyyy.

![](/images/posts/kenapa-pakai-linux-mas/d5d2cadd5b97c5cd4fadb9e09e8b09ff-mwpxe8do.jpg 'small')
