WhatsApp broadcast tool for a business. A few of my marketing colleagues already use it to send campaigns.

WhatsApp goes out through [Sumopod](https://sumopod.com). The site is deployed on Vercel. The API runs on a VPS.

## Stack

- Vue, TypeScript, Vite, Vue Router, Pinia, and Tailwind CSS
- Bun, Elysia, PostgreSQL, and Drizzle
