Flex Studio is the agency I wanted to have. I started it in Yogyakarta in 2024 so client work would live under one name, from the first layout through deployment.

A business should get a site or a piece of design that works and looks cared for. The studio takes websites, interfaces, and graphic design. Some jobs are a landing page. Others need a database, a small CMS, and a deploy I can hand over.

The public site is the front door. It shows the services, a few finished projects, and a way to start a conversation.

## Stack

The studio site is Next.js. Client work is React, Next.js, and Vue with Nuxt. State sits in Zustand or Pinia, server data in TanStack Query, and Supabase when a project needs a backend.
